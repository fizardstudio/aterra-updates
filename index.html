Browser Akselerasi & Produktivitas Kerja

Browser kustom super ringan yang dirancang khusus untuk memotong delay jaringan kementerian, mengamankan privasi dari tracker, dan mempercepat input dokumen kementerian ATR/BPN.

Pelajari Fitur

Fitur Andalan Aterra SC

Didesain secara taktis untuk menyelesaikan berbagai bottleneck operasional staf kantor pertanahan.

Speed Booster Akselerasi

Dilengkapi static asset caching agresif, caching biner wilayah BPN (/getwilayah) instan 0ms dari RAM, DNS cache bypass Windows, preconnect domain CDN esensial, TCP Fast Open Chromium, dan Keep-Alive connection tuning untuk memangkas delay handshake SSL.

Dua Mode Hapus DI Ganda

Bersihkan entri Daftar Isian (DI) yang ganda secara instan. Gunakan Alt+D untuk menghapus seluruh duplikat, atau tekan Alt+E untuk menghapus duplikat tambahan dengan menyisakan tepat 1 baris entri asli.

Multi-Profile Autofill System

Simpan dan kelola banyak profil staf/petugas pertanahan untuk pengisian otomatis formulir Buku Tanah, Surat Ukur, entri data, dan dokumen BPN lainnya secara cerdas. Rekam data isian formulir aktif dengan tombol Alt+Shift+S, dan ganti profil kerja secara instan menggunakan tombol Alt+Shift+P.

100% Bebas Forensik Telemetri

Berbeda dengan browser kementerian (seperti entri-dokumen 6.2.2) yang melacak dan mengirimkan detail aktivitas laptop ke server eksternal, Aterra SC memblokir seluruh pengiriman log. Aktivitas Anda terjamin privat.

Kemandirian Lisensi Offline

Validasi lisensi dilakukan murni secara lokal menggunakan file kunci enkripsi tanpa memerlukan koneksi internet, memastikan browser tetap andal digunakan pada kantor pertanahan di daerah terpencil.

Desain Window Modern

Dilengkapi interface frameless minimalis, visual progress bar download rilis hot-update yang mulus, dan pemilah memori Chromium terisolasi guna menjaga kestabilan browser dari resiko lag.

Smart Prefetch & Dynamic Cache

Secara otomatis memuat sub-catatan Buku Tanah di latar belakang. Kueri data POST di-cache secara dinamis dengan body hashing terurut (mengabaikan CSRF Token) dan fitur pembersihan cache instan jika terdeteksi mutasi data.

Dukungan Mode Gelap (Dark Mode)

Kurangi radiasi cahaya putih silau dengan satu kali klik. Sangat aman untuk membaca peta bidang dan dokumen.

Aksi / Fungsi Kombinasi Keyboard Keterangan

Hapus Seluruh Entri DI Ganda Alt + D Menghapus semua entri Daftar Isian yang terdeteksi ganda.
Hapus DI Ganda & Sisakan 1 Alt + E Membersihkan baris ganda, menyisakan tepat 1 entri asli (Praktis!).
Aktifkan / Matikan Mode Gelap Alt + Shift + D Mengaktifkan atau mematikan tema gelap secara instan.
Simpan Formulir ke Profil Aktif Alt + Shift + S Menyimpan isi teks form input ke database profil autofill.
Pindah ke Profil Aktif Berikutnya Alt + Shift + P Berganti ke akun SSO/pegawai berikutnya secara bergiliran.
Buka Tab Baru Ctrl + T Membuka halaman utama baru dalam tab.
Buka Jendela Baru Ctrl + N Membuka window Aterra Browser yang baru.
Tutup Tab Aktif Ctrl + W Menutup halaman tab yang sedang aktif.
Tab Selanjutnya / Sebelumnya Ctrl + Tab / Ctrl + Shift + Tab Navigasi cepat berpindah antar tab.
Perbesar / Perkecil Zoom Halaman Ctrl + + / Ctrl + - Mengubah skala ukuran teks dan visual halaman web.
